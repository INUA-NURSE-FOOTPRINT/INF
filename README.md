# 🌍 Inua Nurse Footprint (INF) Website

Welcome to the official website repository for **Inua Nurse Footprint (INF)** — a student-led initiative founded by Israel Alex Makori, 2025/2026 Chairperson of the Nairobi University Nursing Students Association (NUNSA).

---

## 🚀 Mission

INF’s mission is to empower nursing students through mentorship, mental health support, community outreach, welfare programs, and alumni engagement — building a better next generation of nurses.

---

## 📑 Project Overview

This website serves as the **official online presence of INF**. It offers:
- Information about our **vision, mission, objectives, and leadership**
- Access to **mentorship, mental health, and support forms**
- Opportunities for **volunteers, partners, and alumni** to connect and engage
- Updates on **events, outreach activities, and resources**

The site is built with **HTML, CSS, and JavaScript** and is intended for deployment via **GitHub Pages** for free access.

## 💡 How to Deploy using GitHub Pages

1. [Create a GitHub repository](https://github.com/new) and upload all files and folders as shown above.
2. Go to your repository **Settings > Pages**.
3. Set the branch to `main` and the folder to `/ (root)`. Save.
4. Wait a moment — your website will be live at:
   ```
   https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/
   ```
5. Share your link!
